# 新增示例：Material 涟漪按钮

`tkdeft` 本身不带组件，但"从零件到控件"这一步一直只有文字说明。
这次补了一个**能直接跑、也能当模板抄**的完整示例：

```bash
python examples/ripple_button.py                # 默认自动挑栅格引擎
python examples/ripple_button.py --engine tksvg # 换引擎看每帧开销
python examples/ripple_button.py --check        # 自检，不开窗口
```

它做的事：圆角按钮 + 按下处扩散的涟漪（500 ms，缓出 + 淡出）、悬停 / 按压 /
焦点 / 禁用四个状态、空格与回车触发、`T` 换主题。

## 值得单独说的几点

* **半透明涟漪没有用 `create_oval`**：Tk 的 canvas item 没有逐像素 alpha。
  示例在 Pillow 里算「圆 ∩ 圆角矩形」的遮罩，超采样 3 倍再缩回，得到一张
  与按钮等大的 RGBA 图层，`create_image` 贴上去。
* **动画进度按 `time.monotonic()` 算**，不是每帧累加 16 ms——
  主线程卡一下，下一帧直接跳到正确进度，整段动画的时长不会被拖长。
* **每帧全量重绘**在这个尺寸下完全够用：一个 200×48 的按钮，
  中位耗时 `skia` 0.42 ms、`pillow` 0.38 ms，默认的 `tksvg` 也只要 4.66 ms
  （60 fps 的预算是 16.7 ms）。

## 顺手记下三个坑

写这个示例时踩到的、文档里原来没写清楚的：

1. `class MyButton(DCanvas, DDrawWidget)` 会直接 MRO 报错——
   `DDrawWidget` 已经继承 `DCanvas`，只写后者就行；
2. `draw_roundrect(..., tags=...)` 在**SVG 回退路径**上会抛
   `Invalid attribute 'tags' for svg-element <rect>`，打标签要用
   `addtag_withtag(返回的 item id)`；
3. 先 `pack()` 再 `mainloop()` 时，`<Configure>` 往往在**映射之前**就发完了，
   而 `DDrawWidget._draw()` 在未映射时直接返回——控件会一直空白，
   直到鼠标划过。补一个 `<Map>` 绑定即可。

另外还发现：**`PrintWindow` 抓不到 canvas 上的半透明叠加层**（窗口里看得见、
截图里没有），所以文档插图改成"引擎渲染的底色 + 示例自己的 `ripple_layer()`
逐帧合成"。这一条已经写进 [常见问题与排查](../../usage/faq.md) 第 13 条。
