# 早期版本回顾（`0.0.1` – `0.0.7`）

这几版是 tkdeft 起步阶段的记录，日期沿用最早那份更新日志。

| 版本 | 内容 |
| --- | --- |
| `0.0.7` | 模板库 `Fluent` 拆出去，成为独立的 [tkfluent](https://pypi.org/project/tkfluent) |
| `0.0.6` | 模板组件 `DBadge` 增加 `style=accent`，调整自定义窗口 |
| `0.0.5` | 主题改为 `theme(mode=..., style=...)`，不再需要 `DDarkButton` 这类成对的组件；新增 `DWindow.wincustom` 自定义窗口（仅 Windows） |
| `0.0.3` / `0.0.4` | 补依赖（两次） |
| `0.0.2` | 补充模板组件 `DEntry`、`DFrame`、`DText`、`DBadge`（详见 [2024-01-25](2024-01-25.md)） |
| `0.0.1` | 首个版本，模板组件 `DButton` |

从这里开始，tkdeft 的方向就定下来了：**用矢量绘图生成图片，再交给 `Canvas` / `Label` 显示**，
具体走 SVG 还是进程内栅格化，交给可插拔的引擎决定。
